## 프로젝트가 무엇인가

"2027 심슨 보카 DAY별 주관식 테스트" PDF(공무원 영어 필수 어휘집)를 기반으로 한
**게임형 영어 단어 복습 웹앱**. 사용자가 업로드한 PDF에서 **48일 × 50단어 = 총 2,400단어**를
추출해 데이터로 쓰고 있다.

- 영어 단어가 하나씩 나오고, 한글 뜻 4개 중 정답을 터치하는 4지선다 퀴즈
- 정답 시 폭죽/콤보/마스코트 리액션 등 게임 요소
- 에빙하우스 망각곡선 기반 복습(SRS), 오답 정답 시트, 이어하기, 학습 기록
- 서버 없음. 순수 정적 단일 페이지(HTML+JS), 모든 상태는 localStorage

## 현재 기능 요약 (v. 49909f3)

- **홈**: 48개 DAY 그리드(별점/왕관), 통계(클리어 DAY·별·마스터), 이어하기 배너,
  망각곡선 복습 카드(지금 복습할 개수/다음 복습 시각), 복습 노트, 학습 기록, 연속 학습일
- **퀴즈**: 큰 단어 카드 + 2×2 뜻 선택지(번호 없음, 길면 글자 자동 축소),
  문제 등장 시 영어 발음 자동 재생, 정답 시 폭죽+콤보+햅틱+효과음 후 한글 뜻 TTS,
  오답 시 하단 정답 시트(자동 전환 없음, 계속하기 버튼) + 세션 끝 재출제
- **복습(SRS)**: 틀린 직후→1일→3일→7일→14일→30일→마스터, 단계 성장(🌰→👑),
  이른 복습 무효, 복습 세션 최대 20개
- **기록**: 세션별 이력(정답률·점수·콤보·시각), 연속 학습일, 평균 정답률
- **이어하기**: 문제 위치·점수·콤보·오답·재출제 큐까지 localStorage에 저장, 배너/DAY 재탭으로 복원
- **기타**: 음소거 토글(효과음+TTS), PC 숫자키 1~4, PWA
