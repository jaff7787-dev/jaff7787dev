# 인수인계 문서 (4) 요청별 조사 내역과 기획

각 사용자 요청에 대해 어떤 조사를 했고, 어떤 근거로 어떻게 기획해 구현했는지 정리.

---

## A. 망각곡선 복습 시스템 (요청 2)

### 배경 지식/근거
- 에빙하우스 망각곡선: 학습 직후 급격히 잊고, **잊기 직전에 복습**하면 기억이 장기화되며
  복습 간격을 점점 늘릴 수 있다 (간격 반복, Spaced Repetition).
- 라이트너 박스(Leitner)식 단계 시스템이 구현이 단순하고 사용자에게 직관적.
  (Anki류 SM-2 알고리즘은 난이도 자가평가가 필요해 4지선다 게임과 안 맞음)

### 기획 결정
- 간격: **틀린 직후(즉시) → 1일 → 3일 → 7일 → 14일 → 30일 → 졸업(마스터)**
  - `SRS_IV=[1,3,7,14,30]`일. "틀린 직후" 단계는 오답 시 due=now로 표현되어
    직후 재도전/재출제가 첫 복습을 겸함
- 오답 시 **무조건 0단계로 리셋** (부분 강등보다 단순하고 보수적)
- **이른 복습 무효**: due가 안 된 카드를 맞혀도 레벨업하지 않음
  (망각이 일어나기 전 복습은 기억 강화 효과가 낮다는 원리 반영, 도장깨기 악용 방지)
- 게임화: 단계를 식물 성장으로 표현 🌰씨앗→🌱새싹→🌿줄기→🌳나무→🌸꽃→👑마스터,
  마스터 순간 왕관 배너+폭죽+전용 사운드
- 트래킹(요청사항): 카드별 ✅성공 복습 횟수(rc), ❌오답 횟수(wc), 다음 복습 시각,
  단계 게이지(5칸 도트)를 복습 노트 화면에 표시
- 복습 세션은 due 오래된 순 최대 20개 (과부하 방지)
- 홈에 "지금 복습할 단어 N개" / 없으면 "다음 복습: N시간 후" 표시

## B. 모바일 사운드/햅틱 (요청 2·4)

### 조사/원인 분석 (요청 4 "사운드가 안 나와")
- iOS 사파리(및 일부 모바일 브라우저)는 **사용자 제스처 안에서** 오디오를 시작해야 하며,
  역사적으로 touchstart가 아닌 **touchend/click**에서만 잠금이 풀림
- 표준 해법: 제스처 핸들러에서 AudioContext 생성 + `resume()` + **무음 버퍼 1샘플 재생**
- 또한 컨텍스트가 suspended인 동안 스케줄한 노트는 소실됨 → `resume().then(play)` 필요

### 구현 결정
- `['touchstart','touchend','pointerdown','mousedown','click','keydown']` 전부에 언락 리스너(capture, passive)
- 효과음은 WebAudio 오실레이터 합성 (파일 없음, 단일 파일 유지 목적)
  - 정답: 988→1319Hz 트라이앵글 + 2637Hz 스파클 (동전 딩동), 레벨업: 상승 아르페지오,
    오답: 220/180Hz 사각파 부저, 콤보/팡파르: 화음 진행
- 햅틱은 `navigator.vibrate` 패턴 차별화: 탭 8ms / 정답 [12,40,24] / 오답 [70,50,70] /
  콤보 [12,30,12,30,40] / 마스터·팡파르 롱 패턴. (iOS 사파리 미지원 — 사운드/비주얼로 보완)
- 음소거 토글은 효과음+자동 TTS를 함께 제어, localStorage 저장

## C. 이어하기(세션 복원) 기획 (요청 3)

- 저장 시점: 세션 시작 + **매 답변 직후** (`idx+1`로 저장해 재답변 중복 방지)
- 저장 내용: 문제 배열 전체(선택지 순서·재출제 포함)·위치·점수·콤보·정답수·오답목록·SRS 스케줄 로그
- 복원 UX: ① 홈 상단 "▷ DAY 1 이어하기 · 26/50 · 💎점수" 배너 (✕로 폐기),
  ② 같은 DAY 셀을 다시 탭해도 이어하기 (새 시작으로 실수 덮어쓰기 방지)
- 세션 완료 시 스냅샷 삭제 → 학습 기록으로 이관
- 다른 DAY를 시작하면 기존 일시정지 세션은 덮어씀 (배너가 항상 보이므로 인지 가능)

## D. 학습 기록/스트릭 기획 (요청 3)

- 세션 완료마다 `{시각, 유형(day/review), 라벨, 문제수, 정답수, 정답률, 점수, 최고콤보}` 적재 (최대 300개)
- 파생 지표: 🔥연속 학습일(오늘 또는 어제부터 역산), 총 세션, 총 문제, 평균 정답률
- 홈 헤더에 스트릭 한 줄 노출 ("N일 연속 학습 중!") — 습관 형성 동기부여 (듀오링고 스트릭 차용)

## E. 오답 UX 개편 (요청 7) — 조사 내역

### 웹 조사 결과 (2026-07-05 실시)
- 듀오링고: 오답 시 정답을 보여주는 시트/인터스티셜이 뜨고 **Continue 버튼을 눌러야만 진행**
  (자동 진행을 없애달라는 확장프로그램이 있을 정도로 확고한 패턴). 틀린 문항은 **레슨 끝에 재출제**
- 학습앱 설계 가이드: "약한 피드백은 '틀렸음'만 알려주는 것. 좋은 피드백은
  ① 정답을 맥락과 함께 명시, ② 무엇이 틀렸는지 강조, ③ 같은 항목을 나중에 재노출"
- SRS 계열(Anki/RemNote 등): 오답 카드는 간격을 리셋해 더 자주 재출제
- 참고 소스:
  - https://chromewebstore.google.com/detail/duoleavemealone-for-duoli/clipadhhddnpnocanhnbonnhppdibnpf
  - https://www.polychatapp.com/blog/language-learning-application
  - https://studycardsai.com/blog/language-learning-spaced-repetition-app
  - https://www.sciencedirect.com/science/article/pii/S0360131523002439 (반복 오답 연구)

### 기획 → 구현 매핑
| 조사에서 얻은 원칙 | 구현 |
|---|---|
| 자동 전환 금지, 명시적 확인 | 하단 정답 시트 + 배경 딤 + "알겠어요, 계속하기" 버튼 (버튼 눌러야 진행) |
| 정답을 크게, 내 오답과 대비 | 시트에 단어+뜻 크게 / 위쪽 선택지에 내 답(빨강)·정답(초록) 유지 |
| 청각 강화 | 시트 등장 시 한글 뜻 자동 TTS + "🔊 발음·뜻 다시 듣기"(영→한 순차) |
| 같은 세션 내 재노출 | 틀린 문제를 큐 맨 뒤 재출제(선택지 재셔플), 맞힐 때까지 반복, "🌀 다시 만난 단어!" 태그 |
| 장기 재노출 | 기존 SRS 카드 리셋(문서 A) + "복습 노트에 담았어요" 안내 |
| 통계 왜곡 방지 | 재출제는 +5점 고정, 정답률·별점·맞힌 문제 수는 첫 시도 기준 |

## F. 자동 TTS 기획 (요청 6)

- 문제 등장 200ms 후 영어 자동 재생 (같은 문제인지 확인 후 재생 — 빠른 전환 시 잘못된 단어 방지)
- 정답 시: 효과음(≈0.4s) → 430ms 시점에 한글 뜻 TTS → **최소 대기시간과 TTS 종료 둘 다 충족해야** 다음 문제
  (onend/onerror + 6초 안전장치, 헤드리스/음성 없는 기기에서도 진행 보장)
- 오답 시: 정답 시트가 떠 있는 동안 한글 뜻 TTS (진행은 버튼으로만)
- 읽기 텍스트 정리 규칙(`cleanMeaning`): 품사표기(v./a./n./ad. 등) 제거, `[대안어]` 통째 제거
  (예: "보존[보호]하다"→"보존하다"), 괄호는 기호만 제거하고 내용 유지, `;`→`,`, 선두 `-` 제거

## G. 시각 디자인 방침 (요청 1·5)

- 사용자 명시 요구: "AI 스타일 작은 글씨 금지, 굵직하고 보기 좋게" → Pretendard ExtraBold(800) 기본,
  단어 44px, 큰 터치 타깃
- 스타일: 플레이풀 네오브루탈 (3~4px 잉크색 테두리, 하드 섀도우 4px, 파스텔 그라데이션 배경,
  둥근 모서리, 이모지 캐릭터), 배경에 떠다니는 아이콘 데코
- 선택지: 사용자 요청으로 2×2 그리드, 번호 배지 제거, 가운데 정렬,
  뜻 길이에 따라 15.5→13.5→12px 자동 축소 (레이아웃 깨짐 방지)

## H. 앞으로 하면 좋을 것 (미착수 아이디어)

- 복습 알림 (Pages는 푸시 불가 → PWA 알림 or 사용자가 원하면 다른 채널)
- 뜻→단어 역방향 퀴즈 모드, 철자 입력 모드
- 학습 기록 그래프(주간 히트맵), DAY별 정답률 추이
- 효과음 종류 선택/볼륨 슬라이더
- localStorage 백업/복원 (기기 간 이동) — 내보내기/가져오기 버튼
