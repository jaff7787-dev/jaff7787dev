# 보카 퀘스트 🐥 — 심슨 보카 2027 게임형 복습 앱

"2027 심슨 보카 DAY별 주관식 테스트" PDF의 **48일 × 50단어 (총 2,400단어)** 를
게임처럼 복습하는 웹앱입니다. 설치나 서버 없이 브라우저에서 바로 동작합니다.

## 실행 방법

- **웹에서 바로**: https://jaff7787-dev.github.io/jaff7787dev/ (GitHub Pages 자동 배포)
- **파일로**: `index.html`을 브라우저에서 열면 끝
- 휴대폰 브라우저 메뉴에서 **"홈 화면에 추가"** 하면 일반 앱처럼 전체화면으로 실행돼요 (PWA)
- PC에서는 숫자키 1~4로도 정답 선택 가능

브랜치에 푸시하면 `.github/workflows/pages.yml`이 GitHub Pages로 자동 배포합니다.

## 👨‍👩‍👧 프로필 & 기기 연동

- **GAME START → 프로필 선택**: 넷플릭스처럼 프로필을 고르고(없으면 닉네임 필수로 생성), 프로필별로 진행도·복습·기록이 따로 쌓입니다.
- **다른 기기와 연동**: 첫 프로필을 만들면 가족 클라우드(kvdb.io, 가입 불필요)가 자동 생성됩니다.
  프로필 화면 하단 **[📋 가족 코드 복사]** → 다른 기기에서 **[🔗 가족 코드로 연결]**에 붙여넣으면
  같은 프로필 목록이 뜨고 어느 기기서든 이어서 누적돼요.
- **로컬 우선**: 인터넷이 없어도 기기에 저장하며 정상 동작하고, 연결되면 자동 병합됩니다
  (별점은 높은 기록, 복습 카드는 진행 많은 쪽, 학습 기록은 합집합).

## 게임 방법

1. 홈에서 **DAY(1~48)** 를 선택하면 그날의 50단어 퀴즈가 시작됩니다.
2. 영어 단어가 하나씩 나오고, 4개의 뜻 중 정답을 터치합니다.
3. 정답이면 🎉 폭죽 + 콤보 보너스, 오답이면 정답을 보여주고 **오답노트**에 자동 저장됩니다.
4. 정답률에 따라 별(★)을 획득: 50% ⭐ / 70% ⭐⭐ / 90% ⭐⭐⭐ (3개 달성 시 👑)

## 🧠 망각곡선 복습 시스템

틀린 단어는 에빙하우스 망각곡선에 맞춰 자동으로 복습 스케줄이 잡힙니다.

- 복습 주기: **틀린 직후 → 1일 → 3일 → 7일 → 14일 → 30일 뒤 졸업(마스터 👑)**
- 맞힐 때마다 단계 성장: 🌰 씨앗 → 🌱 새싹 → 🌿 줄기 → 🌳 나무 → 🌸 꽃 → 👑 마스터
- 복습 중 틀리면 🌰 처음 단계로 리셋 (다시 자주 나옴)
- 기한이 되기 전에 미리 맞혀도 레벨업되지 않음 (망각곡선상 효과가 없는 이른 복습 방지)
- 홈의 **🔥 지금 복습하기**: 기한이 된 단어만 모아 출제 (한 번에 최대 20개)
- **📒 복습 노트**: 단어별 성장 단계, ✅ 복습 횟수, ❌ 오답 횟수, 다음 복습 시각을 한눈에 확인

## ▶️ 이어하기 & 📊 학습 기록

- 퀴즈를 풀다가 앱을 닫거나 홈으로 나가도 **진행 상황(문제 위치·점수·콤보·오답)이 자동 저장**됩니다.
  홈의 이어하기 배너 또는 해당 DAY를 다시 누르면 끊긴 문제부터 계속돼요. (✕로 삭제하면 처음부터)
- 세션을 끝낼 때마다 **학습 기록**이 쌓입니다: 날짜별 세션 목록(정답률·점수·최고 콤보),
  🔥 연속 학습일, 총 학습 세션 수, 푼 문제 수, 평균 정답률.

## 기능

- 🔥 연속 정답 콤보 & 점수 시스템 (5콤보마다 폭발 이펙트)
- 📳 모바일 햅틱(진동) 피드백 — 정답/오답/콤보/마스터마다 다른 패턴
- 🎵 게임 효과음 (정답 딩동↑, 레벨업 아르페지오 등) — 모바일 오디오 언락 처리, 음소거 토글
- 🐥 정답/오답에 반응하는 마스코트와 응원 말풍선
- 🔊 발음 듣기 (브라우저 TTS)
- 💾 진행도·별·복습 스케줄 자동 저장 (localStorage — 같은 브라우저에서 유지)
- ✍️ Pretendard 폰트 서브셋 내장 — 굵고 큼직한 타이포그래피

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (화면·로직·이펙트·서브셋 폰트 내장) |
| `vocab.js` | PDF에서 추출한 단어 데이터 (`VOCAB[day][n] = {w: 단어, m: 뜻}`) |
| `Pretendard-*.otf/ttf` | 원본 폰트 (빌드 시 서브셋 소스로 사용) |
